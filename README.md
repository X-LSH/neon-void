# NEON VOID · 霓虹虚空

霓虹赛博朋克风格的**纵向下卷弹幕射击**。零构建、零依赖、纯前端，浏览器打开即玩。

> 在霓虹灯管般的弹幕中穿梭，粒子炸裂的视觉爽感 + 不断挑战自我极限分数。

## 玩法

自动开火，你只需要专注走位。

| 操作 | |
| --- | --- |
| `WASD` / `↑←↓→` | 移动飞船 |
| （自动） | 飞船持续朝正上方射击，无需按键 |
| 手指在游戏区拖动 | 手机端操控（飞船浮在手指上方，不被拇指盖住） |
| `ESC` / `P` | 暂停 |
| `M` | 音效开关 |

- **生命** 3 格。被击中后 1.35s 无敌并清掉近身弹幕 —— 不会「一发中弹撞进第二发」。
- **连击** 2.2 秒内连续击杀累积倍率（封顶 ×5），受伤立即断连。
- **道具** 散射 · 护盾 · 磁铁 · 炸弹 · 加速，击杀概率掉落，精英怪必掉。
- **精英怪** 第 18 波之后出现；**Boss** 每 10 波一次，三阶段弹幕。
- **颜色即规则**：霓虹青 = 我／安全／可拾取；绿 → 橙 → 紫 → 红 = 危险递增；品红闪烁 = 精英。

单局 3–8 分钟（随水平浮动）。

## 本地运行

ES Modules 需要 HTTP 协议（`file://` 会被 CORS 拦），所以有一个零依赖的静态服务器：

```bash
npm run serve     # → http://127.0.0.1:5175/
```

## 验证

两层，缺一不可。

```bash
npm run verify    # Node 裸跑自检（117 项）—— 不需要浏览器
npm run balance   # 难度曲线实测探针（真实跑完若干整局）
npm run e2e       # 真实 Chrome + CDP（82 项）—— 会自动拉起静态服务器
```

- **`verify`**：逐文件语法（`node --check` 不跟随 import，必须逐文件）、文件规模、分层单向依赖、
  调色板无死 token、难度曲线单调性、扫掠碰撞正确性、「结构上不可能穿透」的证明、
  计分数学、存档往返与降级、粒子池不增长、无 Web Audio 时安全降级、
  **20k 步世界压力测试**（分数单调、连击不越界、无「已命中却仍存活」的子弹）、
  死亡与 Boss 索引关不死锁、SPEC 与 config 的数值不漂移。
- **`balance`**：用三个档位的前瞻采样参考玩家真跑整局，实测单局时长、波次标尺、
  子弹峰值与上限余量、 Boss 耗时，并**交叉验证档位之间有单调区分度**
  （探针本身可信才有资格谈平衡）。
- **`e2e`**：真实键盘与真实触摸、逐层数像素、完整跑完死亡→结算→排行榜落盘、
  实测帧率、390px 窄屏、桌面端零泄漏的双向验证。

## 结构

```
src/
  core/     循环 · 输入 · 视口 · 音频 · 音乐 · 存档 · PRNG   （不含任何游戏语义）
  game/     物理 · 敌机 · 弹幕 · 波次 · Boss · 计分 · 掉落   （不碰 DOM/Canvas/Audio）
  render/   调色板 · 伪辉光 · 粒子池 · 形状 · 背景 · 场景     （只读）
  ui/       HUD · 五个界面面板
  scenes/   战斗会话
docs/SPEC.md  ← 唯一真相源：改设计先改规格书，再改代码
```

三条架构红线：

1. **`game/` 不碰 DOM、不碰 Canvas、不碰 Audio。** 这不是洁癖 ——
   它是上面那 117 项自检能在 Node 里毫秒级跑完的唯一原因。
2. **`core/` 不认识游戏概念。** 画布尺寸与步长由调用方注入；反向 import 是分层倒置。
3. **`render/` 只读。** 它不得修改任何游戏状态；调色板是颜色的唯一真相源。

## 存档

存在浏览器 `localStorage`（键 `neonvoid.save.v1`），带版本字段，版本不符即丢弃重建。

> **清除浏览器缓存会丢失存档。排行榜仅保存在本机，不同设备/浏览器不互通。**

## 技术要点

- **固定步长 1/60s + 渲染插值**，禁用 `Math.random()`（确定性 PRNG）——
  所以「同种子同输入 → 逐位一致」是可断言的。
- **伪辉光**：同一形状描 3–4 遍，而不是 `ctx.shadowBlur`
  （后者是 Canvas 2D 里最贵的参数，每帧上千次调用直接掉帧）。
- **子弹按 kind 批处理成一次 path**：900 发子弹的绘制成本是固定 6 次状态切换。
- **粒子池 TypedArray + 环形覆盖**，容量永不增长，热路径零对象分配。
- **音频全部程序生成**（Web Audio 合成 + 16 分步进音序器），零外部文件、零版权风险；
  环境不支持时全部降级为 no-op，绝不抛异常。
